# K-AutoTrader AI v0.5
모의 백테스트만 제공하며 실제 증권사 주문과 AI 머신러닝 기능은 없습니다.

## 배포
권장: GitHub 저장소에 이 폴더 내용 전체를 업로드하고 Netlify의 Import from Git으로 연결합니다. Netlify가 빌드할 때 netlify/functions/prices.mjs를 서버 함수로 배포합니다. ZIP은 압축 해제하여 폴더 구조를 유지하세요. 기존 사이트에 단순 HTML만 올리면 서버 함수가 동작하지 않습니다. Netlify Drop 수동 배포는 함수 빌드 지원 여부를 확인해야 합니다.

## 데이터
https://aikstockdata.com/data/public/s/{종목코드}_history.json
데이터 제공처가 변경되거나 서버 접근을 차단하면 오류가 납니다. 마지막 확정 일별 시세이며 실시간이 아닙니다. 데이터 사용 조건을 확인하세요.

## 전략
전일 종가 및 이전 5일/20일 이동평균 기반 신호를 다음 날 시가로 체결합니다. 종목당 2만원 제한, -3% 손절 +5% 익절은 전일 종가 기반 다음날 시가 주문이며 보장된 손절 가격이 아닙니다. 거래 비용은 예시 가정입니다. 종목별 단독 백테스트이고 자동 종목 탐색은 미구현입니다. 조정주가 미사용으로 액면분할 등 발생시 결과 왜곡 가능성이 있습니다.
